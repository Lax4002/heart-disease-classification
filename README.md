# Heart Disease Classification

Machine-learning classification project that predicts the presence of heart disease from clinical attributes.

## Approach
- Exploratory data analysis and visualisation.
- Train/test splitting and feature inspection.
- Logistic Regression, K-Nearest Neighbours and Random Forest baselines.
- Cross-validation.
- Randomized and grid-search hyperparameter tuning.
- Evaluation with accuracy, precision, recall, F1 score, confusion matrix and ROC analysis.

## Stack
Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn.

## Repository contents
- `heart-disease-classification.ipynb` — complete analysis and modelling notebook.
- `heart-disease.csv` — dataset used by the notebook.
- `requirements.txt` — dependencies.

## Data source
The project uses the well-known UCI Cleveland heart-disease dataset.

## Note
This is a portfolio learning project demonstrating supervised classification, model comparison and evaluation.
